# Ceph-CSI 安装使用
[ceph/ceph-csi: CSI driver for Ceph (github.com)](https://github.com/ceph/ceph-csi/tree/devel) 
由于 ceph 的支持在 kubernetes 1.28 后已废弃，所以需要安装 [CephFS RBD CSI driver](https://github.com/ceph/ceph-csi)，才能使用 cephfs 作为存储
前置：需要在 ceph 提前建好用户并且赋予权限，建好子卷组，默认为 csi （可在ceph-csi-conf中修改）
所需权限如下
![image.png](https://cdn.nlark.com/yuque/0/2024/png/46412420/1724121538074-eb3b96ea-86b0-40b5-9e3f-1842d2a62e91.png#averageHue=%23141921&clientId=ue3e0536a-2ad9-4&from=paste&height=257&id=u744f990e&originHeight=385&originWidth=1571&originalType=binary&ratio=1.5&rotation=0&showTitle=false&size=43255&status=done&style=none&taskId=ua1ebf369-9c39-4eee-b0a4-e24e27ee896&title=&width=1047.3333333333333)
可以通过以下命令创建用户
```shell
USER=csi-cephfs
FS_NAME=cephfs
SUB_VOL=csi
ceph auth get-or-create client.$USER \
  mgr "allow rw" \
  osd "allow rw tag cephfs metadata=$FS_NAME, allow rw tag cephfs data=$FS_NAME" \
  mds "allow r fsname=$FS_NAME path=/volumes, allow rws fsname=$FS_NAME path=/volumes/$SUB_VOL" \
  mon "allow r fsname=$FS_NAME"
```
创建子卷组
```shell
ceph fs subvolumegroup create VOLUME_NAME GROUP_NAME
```

1. 创建命名空间 ceph-csi
```yaml
apiVersion: v1
kind: Namespace
metadata:
  creationTimestamp: null
  name: ceph-csi
spec: {}
status: {}
```

2. 创建 ceph-csi-config configmap，需要配置 clusterID，monitors

在 ceph 集群使用 `ceph mon dump` 获取
```yaml
#
# /!\ DO NOT MODIFY THIS FILE
#
# This file has been automatically generated by Ceph-CSI yamlgen.
# The source for the contents can be found in the api/deploy directory, make
# your modifications there.
#
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: "ceph-csi-config"
data:
  config.json: |-
    [
      {
        "clusterID": "ca692ba2-a2de-11ee-8801-ac6175a61599",
        "monitors": [
          "59.47.235.64:6789",
          "59.47.235.61:6789",
          "59.47.235.60:6789"
        ],
        "cephFS": {
          "subvolumeGroup": "dev_ops"   # 子卷名，csi每申请一个pv便会在其下生成一个目录
        }
      }
    ]
```

3. 创建 ceph-config
```yaml
---
# This is a sample configmap that helps define a Ceph configuration as required
# by the CSI plugins.

# Sample ceph.conf available at
# https://github.com/ceph/ceph/blob/master/src/sample.ceph.conf Detailed
# documentation is available at
# https://docs.ceph.com/en/latest/rados/configuration/ceph-conf/
apiVersion: v1
kind: ConfigMap
data:
  ceph.conf: |
    [global]
    auth_cluster_required = cephx
    auth_service_required = cephx
    auth_client_required = cephx

  # keyring is a required key and its value should be empty
  keyring: |
metadata:
  name: ceph-config
```

5. 部署 plugin 和 provisioner

plugin 会在每个 node 节点上运行，并注册插件接口。
注意在创建 cephfsplugin 时，保证容器中几个挂载 kubelet 相关目录的位置与 kubelet root-dir 相同（123pan集群为 /data/lib/kubelet）

      priorityClassName: system-node-critical

      hostPID: true

      # resolved through k8s service, set dns policy to cluster first
      dnsPolicy: ClusterFirstWithHostNet

            privileged: true

              add: ["SYS_ADMIN"]
            allowPrivilegeEscalation: true
